# Ramkumar's Birthday Surprise — from Nandhini ♡

A romantic multi-page birthday website with a personal letter, memory gallery, birthday wishes and a final portrait reveal.

## Add photos
Put your photos in `assets/photos/` using these filenames:
- `photo-1.jpg` to `photo-6.jpg` — couple memories / favourite moments
- `birthday-person.jpg` — Ramkumar's portrait for the final reveal

You can use `.png` or `.webp` too, but update the corresponding `src` in the HTML. Use relative paths as provided so the site works under a GitHub Pages project URL.

## Personalize
- `letter.html` — edit the letter so it sounds like Nandhini.
- `memories.html` — edit the captions to match the photos.
- `wishes.html` — adjust the wishes.
- `final.html` — edit the final message if you want to include an inside joke or personal promise.

## Publish with GitHub Pages
1. Upload every file and folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then Save.
5. Open the Pages URL shown in GitHub after deployment finishes.

No framework or build step is required.
