# Ramkumar's Birthday Party-Romance Website — from Nandhini ♡

A Bootstrap 5 multi-page birthday website with a colourful romantic party atmosphere:
- Bootstrap responsive layout and grid
- Custom CSS styling, glassmorphism and 3D hover / tilt effects
- Floating balloons and animated confetti background
- Polaroid-style photo collage
- Personal love letter and birthday wishes
- Final portrait reveal with a confetti burst

## Add your photos
Place these images inside `assets/photos/`:
- `photo-1.jpg` through `photo-6.jpg` — couple photos / favourite memories
- `birthday-person.jpg` — Ramkumar's portrait for the final reveal

Use JPG, PNG or WebP. If changing extensions or names, update the matching image `src` in the HTML files.

## Personalize
Edit `letter.html`, `memories.html`, `wishes.html` and `final.html` to change the message and captions.

## GitHub Pages
1. Extract the ZIP and upload all files/folders to the root of your GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Open the GitHub Pages URL after deployment completes.

Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is needed for those external resources. Custom CSS and JavaScript are included locally.
